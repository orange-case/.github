# Contributing

Thanks for your interest in The Orange Case. This is the default guide for repositories in the orange-case
organization that have no contributing guide of their own.

- **Start with an issue.** Describe the problem or the idea before a larger change, so we can agree on the
  approach first.
- **Work on a branch** and open a pull request against `main`. Keep it focused on one change.
- **Follow the repository's own guide** where it has one. JoustMania is spec-driven: behaviour changes update the
  spec first; see its [contributing guide](https://github.com/orange-case/JoustMania/blob/main/docs/CONTRIBUTING.md).
- **Security problems** go through the [security policy](SECURITY.md), never a public issue.
