# Security Policy

This is the default policy for every repository in the orange-case organization that has no `SECURITY.md` of its
own. A repository's own policy takes precedence (for example
[JoustMania's](https://github.com/orange-case/JoustMania/blob/main/SECURITY.md)).

## Reporting a vulnerability

Please do not put details of a security problem in a public issue.

- Use the repository's **Security > Report a vulnerability** form (GitHub private vulnerability reporting), if it is
  enabled.
- Otherwise open a public issue titled "security contact request" with no details, and a maintainer will arrange a
  private channel.

Include what you found, the version or commit, and steps to reproduce it. These are volunteer projects: we respond
on a best-effort basis, with no fixed timeline.
